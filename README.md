# VELORA Beauty Studio – Online Cosmetics Shopping Website

## About the Project

VELORA Beauty Studio is an online cosmetics shopping website created to make shopping for beauty products easier and more interesting. Customers can explore lipstick products, view different shades, and select products they like.

The main aim of this project is to understand how technology can improve customer experience and help a beauty business grow.

## Objectives

- To make cosmetics shopping simple and convenient.
- To help customers explore different lipstick shades.
- To improve customer engagement through interactive features.
- To create an attractive online shopping experience.
- To understand how digital technology can support business growth.

## Technologies Used

- **HTML:** To create the structure of the website.
- **CSS:** To design the website and make it attractive.
- **JavaScript:** To add interactive features such as shade selection and shopping bag functionality.

## Main Features

1. **Product Display:** Customers can explore different lipstick products.
2. **Shade Selection:** Customers can view different lipstick shades.
3. **Interactive Preview:** Customers can preview product colors.
4. **Shopping Bag:** Customers can add products and view the total price.
5. **User-Friendly Design:** The website is designed to make product browsing easy.
6. **Online Access:** The website can be published online so customers and lecturers can access it through a link.

## Benefits to the Business

- Helps attract more customers through an online platform.
- Makes it easier for customers to discover products.
- Improves customer engagement through interactive features.
- Can help customers make better product choices.
- Supports brand awareness and potential sales growth.

## How to Run the Project

1. Download or clone this repository.
2. Extract the project files if they are in a ZIP folder.
3. Open the project folder.
4. Open `index.html` in a web browser.

## Future Improvements

## Conclusion

VELORA Beauty Studio demonstrates how a simple website can support a beauty business by improving product discovery and customer engagement. It also shows how digital technology can create opportunities for business growth.
